# Changelog

## [1.0.0] - 2024

### Added
- Initial release
- Read Modbus registers (Holding, Input, Coil, Discrete Input)
- Write to Holding registers and Coils
- Support for multiple data types (uint16, int16, uint32, int32, float32, uint64, int64, float64)
- Scan range of registers
- Test if register is writable
- Dark theme matching Home Assistant
- Ingress support for seamless HA integration
